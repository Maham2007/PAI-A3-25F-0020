# PAI-A3: NumPy, Pandas and Matplotlib on measurement data

Programming for AI, Assignment 3 (Fall 2026).

## How to run
1. Install Python 3 and the libraries: `pip install numpy pandas matplotlib pillow ipykernel`
2. Keep the folder structure unchanged (`data/` next to the notebook).
3. Open `Assignment3_Programming_for_AI.ipynb`, select the Python kernel where the libraries are installed, and choose Restart and Run All.
4. The notebook saves `dashboard.png`, `dashboard.pdf` and `wave.gif` in `outputs/`.
